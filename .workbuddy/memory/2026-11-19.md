## Package Project 在 H21 打开即崩 —— 修复 PySide6 6.5 包装类型粘连（18:50）

- 报错：`package/window.py` 的 `horizontalHeader().setSectionResizeMode()`
  抛 `AttributeError: 'PySide6.QtWidgets.QAbstractScrollArea' object has no
  attribute 'setSectionResizeMode'`，窗口构造期崩、工具完全不可用。
- 关键判断：traceback 里的 `python3.13libs/...` **不能**用来判断版本——
  `python3.11libs` 是入口壳，`__path__` 指向真身，H21 加载的业务模块
  `__file__` 也落在 3.13libs。本机双版本无头探针坐实：H21 = PySide6
  6.5.3，H22 = 6.8.3；6.5 按「首次包装时请求的类型」缓存 C++ 指针的
  Python 包装（降级成 QAbstractScrollArea 后派生 API 全丢），6.8 按 C++
  真实类型解析、连显式降级包装都返回 QHeaderView，所以开发机不复现。
- 方案（防御性，不依赖探针）：新增 `houtools/ui/qtcompat.py::rewrap()`
  按 `shiboken6.getCppPointer` 重包，已是目标类型短路（H22 零开销），
  失败告警后返回原对象；调用方用 `hasattr` 守卫，最坏只丢列宽策略、
  窗口仍可开。`package/window.py`、`recipelib/browser.py` 两处表头统一
  接入，`ui/dialogs._rewrap` 改为委托共享层（同款坑，名字保留）。
- 文档/回归：`AGENTS.md` 结构图 + `dev-notes/package_project.md` 补坑表；
  `tests/smoke_test.py` 固化降级→重包、短路、指针传递、列宽策略断言。
- 验证：H22 完整 `smoke_test`（SMOKE TEST OK，reload 顺序里 qtcompat 先于
  dialogs）、`test_theme_tokens`、`test_about_sync`、语法检查全绿；H21
