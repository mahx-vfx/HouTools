Automation自动化批处理#

入口:HouTools → Automation(以 Python Panel 浮动面板打开,可停靠进任意面板布局)

把要执行的操作排成任务队列,点 Start 后依序自动触发,适合收工挂机跑缓存、批处理等重复劳动。

任务类型#

  • 按钮点击 — 对指定节点的指定参数(按钮)模拟点击,如 ROP 渲染、File Cache 写盘。
  • Flipbook — 按帧范围对视口拍屏输出序列图。
  • Webhook — 向指定 URL 发送请求,可用于联动智能家居(如跑完灯光提醒)。
  • 打开DW — 启动外部 Deadline Worker 处理当前工程。

使用要点#

  • 后台线程执行,不阻塞 Houdini 界面;对 Houdini 的调用统一派发主线程,上一任务真正完成后才派发下一个——顺序语义有保证,主线程被解算阻塞多久就等多久。
  • 取消是协作式的,只在任务边界生效;点停止后按钮显示「停止中…」直到当前任务结束。
  • 节点可直接拖入参数路径框(原生投递)。
  • 任务里的节点路径跟随改名:BUTTON_CLICK 任务的节点路径随节点或父级改名实时更新(配置 JSON 与面板槽位同步刷新),像 Houdini 原生参数引用一样;改名/删除反馈走左下角 toast,控制台零提示。
  • 节点被删除时只摘监听、路径保留,槽位显示红色「丢失」标签(不自动改配置);撤销删除或同名重建后自动恢复。无头/农场会话不挂监听、hip 零写入。
  • 配置 JSON 存 $HIP/HouTools_cfg/Automation_json/(跟工程走,多配置文件可切换),执行日志存 $HIP/HouTools_cfg/Automation_logs/。默认配置为本机计算机名,多台机器共用同一工程目录时各写各的配置文件,互不覆盖;「上次使用的配置」也按机器随工程记忆,重开同一工程自动切回。
  • 任务列表改动即存:编辑后 600ms 自动落盘(切配置/Start/关窗时强制保存),崩溃不丢配置;配置被其他机器修改过时,写盘会弹窗让用户选择覆盖 / 另存 / 取消(取消=放弃本次修改,恢复磁盘内容);工具栏「删除」按钮可删除废弃配置(二级确认,物理删除不可恢复)。
  • 「打开DW」任务的软件路径在配置目录的 Automation_Config.json 配置(缺失时自动按默认值补建,可直接编辑);该任务执行前会强制保存当前工程。
  • Flipbook 帧范围支持灵活写法,解析失败时沿用场景当前范围并告警。

Paste as Object Merge粘贴为 Object Merge#

入口:网络编辑器 HouTools 菜单 / 快捷键 Ctrl+Shift+V

在网络编辑器里 Ctrl+C 复制节点后,切到目标网络按 Ctrl+Shift+V,在鼠标位置创建引用节点(而非副本),颜色随源节点。按「目标上下文 × 源类别」自动选择引用方式:

复制的源 → 粘贴目标创建的节点(XXX = 源节点名)
SOP → SOPobject_merge Merge_XXX
SOP → OBJgeo XXX,内含 object_merge Merge_XXX
SOP → LOPsopimport SOP_XXX
SOP → COPsopimport SOP_XXX(仅新 COP,置 usesoppath=1)
SOP → DOPstaticobject Object_XXX
SOP → ROPfetch SOP_XXX(源为 File Cache 时路径追加 /render)
OBJ → SOPobject_merge Merge_XXX
OBJ → LOPsopimport SOP_XXX
LOP → SOPlopimport LOP_XXX
LOP → LOPfetch LOP_XXX
LOP → ROPusdrender XXX
  • 未列出的组合一律跳过(状态栏提示)。
  • 整次操作占用单个 undo 槽,Ctrl+Z 一步撤回。
  • 源路径取 OS 剪贴板文本;文本失效时状态栏按原因提示重新复制(不粘贴副本)。
  • 键位在 HouTools → HouTools Settings... 修改,也可用 Houdini 自带 Hotkey Manager(符号 h.pane.wsheet.houtools_paste_as_object_merge)。

Copy Output Path复制输出路径#

入口:网络编辑器 HouTools 菜单 / 快捷键 Ctrl+Shift+C

网络编辑器里选中节点按 Ctrl+Shift+C,把该节点输出文件所在的文件夹复制到系统剪贴板(如 C:\...\render\TTT,不含文件名),直接粘进文件对话框或其他软件。

  • 对与右键 Open Cache Folder [HT] 同一批节点生效(按输出参数命中:filecache / mantra / karma / usdrender / rop geometry 等,第三方 Arnold 节点带相应参数即支持),选中其他节点时通知提示。
  • 取值与节点右键 Open Cache Folder [HT] 同源:$HIP/$OS 等变量展开后的绝对路径。
  • 目录尚未写出(缓存未落盘)时不复制,左下角红色错误通知;各类失败反馈只走通知模块、不刷控制台。
  • 多选时把命中节点的目录去重后逐行合并复制,未命中的节点忽略。
  • 键位在 HouTools → HouTools Settings... 修改,也可用 Houdini 自带 Hotkey Manager(符号 h.pane.wsheet.houtools_copy_output_path)。

File Cache Paths to AbsoluteFile Cache 路径转绝对#

入口:网络编辑器 HouTools 菜单 → File Cache Paths to Absolute

一键把当前层级所有 File Cache 节点的三个路径参数——basedir(Base Folder)/basename(Base Name)/file(Geometry File)——展开成绝对路径:$HIP/$HIPNAME/$OS/$JOB 等变量冻结成字面值($OS 按节点名替换),相对路径按工程目录($HIP)拼接,工程挪走/换机打开时缓存不再依赖 hip 位置。$HIP/geo/$HIPNAME.$OS.$F.bgeo.sc → D:/shots/SA01/geo/untitled.filecache1.$F.bgeo.sc。三个参数相互独立(File Path 的「组合模式 basedir+basename」与「直接模式 file」两种界面形态都覆盖)。

  • 帧变量原样保留:$F/$F1-9/$FF/$FF1-9(含 ${F4} 花括号形态)不展开,帧编号仍随播放推进;$FPS 等以 F 开头的其他变量不受保护、正常展开。
  • basename 是名称段:只展开变量成字面名($HIPNAME.$OS → untitled.filecache1),不按工程目录拼接;basedir/file 按完整路径处理,目录尾斜杠按原文保留。
  • 已是绝对路径、路径为空、表达式驱动(关键帧/chs 链接)、含反引号内联表达式、op: 等协议路径、参数锁定的参数自动跳过并计入汇总通知——表达式类写静态值会冻结表达式结果,属破坏性改写,直接拒绝;旧版 filecache 没有 basedir/basename 参数时静默忽略。
  • 写回值为正斜杠归一(即最终落盘形态);整批操作单个 undo 槽(Ctrl+Z 一次全还原),单参数写入失败只跳过该参数,不影响其余参数。

Drag & Drop Import拖放导入 .abc / .fbx / .usd#

入口:从资源管理器把 .abc / .fbx / .usd 等文件拖到网络编辑器

松手即在鼠标位置创建导入节点,免去 File → Import 的多步操作(基于 Houdini 官方 externaldragdrop 钩子):

拖放落点.abc 创建的节点.fbx 创建的节点.usd/.usda/.usdc/.usdz 创建的节点
Object 层级(/obj)Alembic Archive,自动构建层级(等价 File > Import > Alembic Scene...)FBX 子网,官方导入器自动命名(等价 File > Import > Filmbox FBX...)—
SOP 层级(geo 内部)alembic SOP 节点file SOP 节点—
LOP 层级(/stage)——sublayer 节点,路径填入 filepath1
  • 支持一次拖入多个文件(.abc/.fbx/.usd* 可混拖),纵向排开;各类整批各占一个 undo 槽。
  • 节点名自动清洗:取文件名主干,中文等非法字符替换为 _,同名自动加数字后缀(FBX 子网由官方导入器命名)。
  • 导入的 FBX 节点不冻结:按官方导入对话框的 Unlock 选项直接导入(官方 File > Import 默认锁定 file 节点、参数只读),落网即可编辑。
  • 非 .abc/.fbx/.usd* 文件不受影响;拖到参数框、视口等其他面板的行为与原生完全一致。
  • 文件损坏时由节点的错误旗标反馈(坏文件拖到 obj 层级可能静默不建子节点;坏 .fbx 走状态栏提示+日志),创建操作本身不会失败。

Capture Viewport to Node视窗截图嵌入节点#

入口:右键任意节点 → Capture Viewport to Node [HT](删除:右键 Delete Viewport Capture [HT],仅带截图的节点显示)

截取当前 3D 视窗,作为网络编辑器背景图钉在节点旁——给关键节点留一张「做出来长什么样」的速览图。

  • 截图为单帧 flipbook:beauty pass(不带网格/gizmo 覆盖层)、视口原始分辨率,直出 JPG。
  • 落盘后按质量 60 重编码 JPG(约为 flipbook 默认档 1/4 体积),放大部分显示仍清晰。
  • 文件存 $HIP/HouTools_cfg/captures/(文件名即节点路径);背景图只存路径引用、不进 hip——工程挪动、换机打开仍有效,hip 不膨胀。
  • 图片锚定节点,节点移动图跟随;节点改名后磁盘文件与背景图自动跟随重命名(改名撤销会原路改回,语义自洽)。
  • 重截同节点自动覆盖旧图;删除节点只清背景图条目、磁盘文件保留(孤儿文件无害,文件名自说明,可手动清理)。
  • Delete Viewport Capture [HT]:一次性删除背景图条目、磁盘文件与标记。
  • 已知局限:父级网络(geo 容器等)改名不跟随,需重截或手动调整。

Paste Bounding Box粘贴边界框#

入口:右键目标节点 → Paste Bounding Box [HT] 子菜单(仅同时带三分量 size 与 t 参数的节点显示,如 box;grid 的 size 是二向量,不显示菜单)

网络编辑器里 Ctrl+C 复制源节点 A,右键目标节点 B,把 A 的包围盒尺寸/中心贴到 B 的 size / t(sizex/y/z ← bbox(A, ...)、tx/y/z ← centroid(A, ...))——做「刚好包住某个模型」的盒子(碰撞体、代理、bounds 可视化)一步到位。

  • Paste Absolute Values [HT]:求值后直接写入;B 参数已有的表达式/关键帧清除替换,锁定参数跳过并在状态栏提示。
  • Paste Expressions [HT]:写入 bbox() / centroid() 表达式,A 变动时 B 实时跟随;A 与 B 同网络用相对路径(../A),跨层级用绝对路径。
  • 绝对值与表达式走同一套求值函数,两种模式结果一致;整次操作单个 undo 槽;源节点有 cook 错误时不写入;源与目标是同一节点时跳过。

Paste Center粘贴中心#

入口:右键目标节点 → Paste Center [HT] 子菜单(所有节点可用)

网络编辑器里 Ctrl+C 复制源节点 A,右键目标节点 B,在 B 正下方创建 transform 节点并接管显示/渲染输出(启用),把 B 的内容平移到 A 的中心位置(px/y/z ← centroid(B)、tx/y/z ← centroid(A) − centroid(B),枢轴落在 B 原中心,后续旋转/缩放绕自身中心)。

  • Paste Absolute Values [HT]:求值后直接写入。
  • Paste Expressions [HT]:写入 centroid() 链接表达式,A 或 B 变动时 transform 实时跟随;A 与 B 同网络用相对路径(../A),跨层级用绝对路径。
  • transform 按 B 所在网络类别创建(SOP/LOP/COP;其余上下文状态栏提示);整次操作单个 undo 槽;源或目标有 cook 错误时不创建;源与目标是同一节点时跳过。

Video to Sequence视频转序列图#

入口:HouTools → Video to Sequence(独立窗口,进任务栏)

用 ffmpeg 把视频提取为图片序列,方便直接喂给 Houdini 的文件序列参数(如相机 Background Image、COP 纹理)。

  • 支持拖放视频文件到窗口,或浏览选择、手输路径。
  • 静帧序列(EXR/PNG/TIF)同样支持:点「浏览」在 Houdini 文件选择器中按折叠序列选择(同一序列折叠成一个选项);拖入或手输单个具体帧只转换该帧。EXR 是线性编码,转换时自动套 sRGB 色彩转换(输出不发暗);适合把渲染 EXR 序列转成低质量 JPG 代理图,再直连相机背景。
  • 相机在 Houdini 浮动操作员选择器中直接选取(列表只显示相机节点),旁边的跳转按钮一键在网络编辑器中定位所选相机。
  • 帧级进度显示;输出质量、起始帧编号、位数、文件名前缀可调。
  • 「编码器」行有 ⓘ 按钮:悬停/点击查看当前实际生效的 ffmpeg/ffprobe 路径(查找有降级序,显示即所用)。
  • 可选自动把输出序列设置到选中相机的 Background Image。
  • 相机分辨率显示与编辑:选中相机后显示其分辨率,宽/高两个输入框直接改写(1~5 位整数校验),「预设」下拉一键填入 1280×720~4096×2160 共 7 档,「确定」写回相机;相机行「匹配素材分辨率」按钮一键把相机分辨率对齐当前素材(防背景拉伸)。
  • 转换前扫描输出目录中的同前缀旧序列,询问后改名 .bak 让位——转换成功才真正删除,取消/失败原样还原,防止新旧帧混杂。
  • 提取可随时取消(探测与转换阶段均可),取消时提示已写入帧数。
ffmpeg 优先使用 Houdini 自带的 $HFS/bin/hffmpeg,无需单独安装;如需指定版本,把 ffmpeg.exe 放到 Documents/HouTools/(配置目录 Documents/HouTools/settings 的上级,即包清单 HouTools.json 里 HOUTOOLS_FFMPEG 的默认值 $HOUDINI_USER_PREF_DIR/../HouTools)即可优先使用,该变量也可改成 exe 完整路径或其他目录。ffprobe 无需单独配置:优先借用 ffmpeg 同目录配套的 ffprobe,缺失时回退 PATH / $HFS/bin/hffprobe。

Package Project打包工程#

入口:HouTools → Package Project(主菜单与网络编辑器菜单均有)

把工程收成可搬走的一包,对应渲染农场提交前的整理:收文件 → 改相对路径 → 保存 → 打 zip。

  • 只扫启用节点、只列用户改过的路径:file / fileName / 贴图路径这类输入参数只要填了值就列出来,文件不存在也列(标「缺失」,打包时跳过);参数处于默认值(isAtDefault)的内置路径(如 karma/hoseksolarmap.rat)不会列出,filecache 的 basedir 例外(它代表实际缓存目录)。$HFS / $HH 里的引用也会列出(是否打包由勾选决定),只过滤真正不是文件的值(空值、节点路径、目录、shfs:/op: 协议、$HIP/galleries、$HIP/backup)。
  • filecache 缓存按真实路径整段收:它的 file 参数($HIP/geo/$HIPNAME.$OS.$F.bgeo.sc)不是实际文件,工具按 sopoutput 求值拿首帧、glob 出整段帧,并把改写目标定为 basedir——下游 chs("…/sopoutput") 引用会自动跟着走。其它输出参数只收已落盘的,未落盘的只作缺失行列出、不复制不改写(「含空输出路径」勾选已移除)。
  • 按文件类型归入官方工程目录:包内不再有统一 assets/ 层,顶层直接是 Houdini 官方 New Project 目录 geo / hda / sim / abc / tex / render / flip / scripts / other,解压后即可当工程用。$HIP/geo/x.bgeo.sc → geo/x.bgeo.sc(类型与首段同名不重复前缀),包外素材才展平目录(D:\proj\tex → tex/D_proj_tex),避免同名覆盖。
  • 参数写法按生成方式区分:另存到包目录 → $HIP/<类型>/…(hip 就住在包目录里,$HIP = 包目录);覆盖当前工程 → $HIP/<包名>/<类型>/…、$JOB/<包名>/<类型>/… 或 <自定义根>/<包名>/<类型>/…。包根可选 $HIP(默认)、$JOB(未设置自动禁用)或自定义绝对路径;另存模式无论包根选哪个,前缀都是 $HIP/<类型>/…。
  • 表达式驱动的参数不改写:chs() 链接 / 表达式 / 关键帧驱动的参数自动跳过——对它写静态值等于把表达式冻成常数(同 File Cache 转绝对的拒绝语义),并计入执行结果的跳过统计;filecache 的 basedir 同查(其 file/basename 只是拼路径的片段,本就不单独收)。
  • 两种生成方式:另存到包目录(默认,生成 <包名>/<hip>_packed.hip,原工程不动)或覆盖当前工程。包名默认「工程名 + -pack」(未保存工程回落 ht_package),可在窗口里改(输入会净化,Windows 禁用符与 .. 被收敛,防止写出包目录之外)。
  • 表格 6 列(勾选 / 节点 / 参数 / 参数现值 / 打包后参数值 / 状态),类型信息并入状态列;数据列列宽可拖,Ctrl+滚轮 缩放表格字号(7–24pt)。扫描期间有全窗口等待遮罩,取消勾选实时联动待复制数/体积,切换工程自动清空上一工程的扫描结果。
  • 帧模板 foo.$F4.exr 原样保留,现有帧整段收进包里;参数改写在一个 undo 组里,Ctrl+Z 可整体撤销。复制/zip 在后台线程执行,运行中关闭窗口即协作取消——复制停在当前文件边界(取消后不进行参数改写与保存),zip 半成品(.part)不落盘。
  • 执行结果面板:完成 / 失败两态,逐条列出复制失败(源路径 + 原因)、改写失败(节点:参数 + 原因)、保存失败与跳过计数,并显示扫描统计。
  • 双击某行跳转到该节点(网络编辑器定位并居中;跳转前自动切 Manual 更新模式,避免 Auto Update / OnMouseUp 下跳重节点当场重烤卡死,恢复在播放条手动选回);右键只有两项:「跳转到节点」「在资源管理器中打开原路径」(Shell API 定位并选中,序列取第一帧)。
  • 「生成 zip」把包目录整体压成 <包根>/<包名>.zip,并在 <包根>/<包名>/package_log.txt 写逐条打包明细(随 zip 归档)。

HDR LibraryHDR 环境贴图库#

入口:HouTools → HDR Library(独立窗口,进任务栏,可全局置顶)

HDR 环境贴图库浏览器:缩略图网格浏览、按文件夹分类、收藏,选中灯光后双击即完成贴图。

库组织#

  • 库按「总目录 / 一级分类子文件夹」组织,左侧栏切换 全部 / ★ 收藏 / 各分类;侧栏右键可新建、打开分类文件夹,空分类也会列出,嵌套子文件夹归入第一级。
  • 首次使用在窗口内「更换目录」指定库目录——无默认目录(HDR 库体积大),未配置时列表空置;目录、缩略图大小、置顶、收藏都存配置目录的 hdr_library.json。

缩略图与贴图#

  • 缩略图由后台线程池调 Houdini 自带 hoiiotool 按需生成(无需安装),缓存在库目录 .thumb_cache/;扫描结果落配置目录的快照 hdr_scan_index.json,下次打开先比对目录修改时间——库没动就直接出网格不重扫,库有增删才重扫跟上(可暂停/停止);HDR 被原地同名覆盖更新时按文件状态等值检出、旧缩略图自动重生成,可疑情形用「刷新」按钮强制全量重扫兜底。
  • 选中一个或多个灯光后双击缩略图,HDR 路径批量写入灯光环境贴图参数——支持 OBJ envlight(Karma,自动关 skymap 程序化天空)、RenderMan dome 灯、LOP domelight 全家族(Solaris);其余灯型给出友好提示;赋值成功/失败有状态栏闪烁反馈,同一贴图 1.2 秒内的重复赋值自动去重(防双击连发重复写参)。
  • 右键缩略图:收藏 / 复制路径 / 打开所在文件夹;收藏项右上角带角标并计入侧栏计数。
缩略图尺寸固定(大小滑条决定),网格不随面板宽拉伸,面板宽窄只改变每列数量——与 Recipe Library 同一套排版逻辑。

Recipe Libraryrecipes 资产库#

入口:HouTools → Recipe Library(独立窗口,进任务栏)

基于 Houdini 22 官方 recipes 的资产面板:卡片网格浏览、树形侧栏过滤、双击/拖拽应用到网络、VEX/Python 代码块、Markdown 文档、数据导入导出。

浏览#

  • 卡片显示缩略图、标签、版本、节点数,支持自定义主题色(右键「自定义颜色」)与收藏角标。
  • 标签可自定义颜色(侧栏标签行右键「自定义颜色」),侧栏行、卡片标签行、预览标签栏三处生效。
  • 树形侧栏按 全部 / 收藏 / 代码块 / 节点参数 / 子菜单 / 标签 / 网络层级 过滤,代码块、节点参数两行恒显(空段计 0);右键仅弹菜单,不切换分组。
  • 侧栏顶部 工具 / 代码块 / 参数 三个显示开关控制对应类型卡片的显隐:全局过滤所有分组视图,状态记忆、默认全开。
  • 搜索框支持 # 前缀只搜标签(如 #pyro),多词 AND 匹配;自定义显示名(支持中文)同步参与搜索。
  • 预览缩略图区域右键可直接 设置缩略图 / 截取缩略图 / 清除缩略图;点击放大:滚轮缩放、中键平移、双击或 Esc 关闭;GIF 显示动图,文档中的视频可播放。

应用#

  • 双击卡片 = 官方工具架体验:参数照抄,视角不拉远(锚点落在视图外才整组平移到视图中心)。
  • 拖拽到网络 = 在落点对齐创建整组节点。
  • 应用前做网络层级匹配检查,不匹配时左下角状态栏给出中文提示(如 SOP recipe 进 LOP 网络)。
  • 应用成功时底部状态栏绿色闪烁反馈,失败红色闪烁;同一配方 1.2 秒内的重复应用自动去重(防双击/拖拽连发重复创建),失败不占去重窗口、可立即重试。
  • node / parm / decoration 预设需先选中目标节点。

代码块#

  • VEX / Python 代码片段卡片:一卡一文件存配置目录的 vex_python_lib/(vex/*.h、python/*.py,文件即数据源);内部名 = 文件名,创建后不可改,中文展示名走「自定义显示名」。
  • 空白网格区右键「新建代码块」创建(实时查重,重名/非法名禁用确认);卡片缩略图即代码高亮渲染(卡片第二行显示代码行数),字号只随卡片高度取档,可读性优先。
  • 代码块卡片右键菜单与 recipe 卡片同套:收藏 / 自定义显示名 / 标签设置 / 自定义颜色 / 设置缩略图等,可给代码块设标签并自定义颜色。
  • 双击卡片 = 把代码追加到全部选中节点的代码参数(VEX→snippet、Python→python,现有内容非空时空行分隔),整批一个 undo。
  • 拖入 VEX/Python 编辑框即插入到光标处(自动修复内建编辑器的多行显示);拖到网络编辑器 = 落点并入代码节点,空白处创建对应节点并填码。
  • 语言不匹配的拖入自动拒绝:落点参数面板显示异语言代码节点时在拖放层直接拦截、Houdini 的写入不执行;网络通路命中异语言代码节点拒绝并入、也不凭空创建异语言节点;拦截不了的旁路落点红色闪烁提示。
  • 预览面板为带行号的代码视图(语言/修改时间/行数),右键「编辑代码」;搜索含代码全文。

元数据与文档#

  • 库只加载「设置 ▸ 库目录」配置的用户文件夹(递归扫描 .hda),出厂库 / Labs 一律不显示;库启动时自动安装,Tab 菜单里的 session tool 从会话开始可用。
  • 自定义显示名、标签(可自定义颜色)、颜色、收藏存配置目录的 recipelib.json,缩略图存配置目录 recipe_thumbs/(相对路径存储,配置目录挪动不失效)。
  • 每条 recipe 可配 Markdown 文档(存配置目录 recipe_docs/),确认/取消模式编辑,渲染支持 GIF 动图与视频(超大 GIF 自动降级为静态首帧,防全帧缓存耗尽内存);主面板有文档时直接渲染文档,无文档回退官方备注;文档/备注渲染区右键「编辑文档」。
  • 文档编辑器回车自动延续列表/勾选框/引用(Obsidian 式):无序同符、有序自增、勾选框续为未勾选、引用可组合列表,空项逐层退出。
  • 文档渲染支持图片尺寸参数与 <br> 换行;中键点击文档区弹出独立详情面板(无边框标题条,可钉住/拖拽/缩放/最大化,未钉住失焦自动关闭)。
  • 版本过滤:「设置 ▸ 显示」开关(默认开)——不显示保存版本高于当前 Houdini 的 recipe(只比大版本段);取消勾选则全部显示,更高版本的卡片左上角带感叹号角标提醒(应用层不做拦截)。
  • 设置缩略图支持两种来源:右键「设置缩略图」选图后框选裁剪(比例与卡片锁定),或「截取缩略图」屏幕框选(所有显示器全屏遮罩,选框可跨屏拖拽,混合 DPI 按各屏取像)。

数据交换#

  • 「设置 ▸ 数据」导出/导入 zip 交换包(元数据 + 缩略图 + 文档 + HDA + 代码块),打包带走、分享。
  • 导入按内部名合并:包内覆盖同名、本地独有保留、收藏取并集;与本地同名定义的 HDA 整文件跳过(避免同名定义二选一的不可预期)。

HouTools Settings设置#

入口:HouTools → HouTools Settings...

HouTools 的统一设置窗口,当前包含两块:

  • 配置目录:只读展示当前生效的配置目录(全部用户配置——快捷键、 Recipe Library 元数据/缩略图/文档/代码块、HDR 库设置、Automation 应用级配置—— 的存放位置)。默认 Documents\HouTools\settings,Houdini 21/22 共用; 窗口内附修改方法:编辑 HouTools.json 包清单的 HOUTOOLS_SETTINGS_DIR 为目标目录绝对路径,重启 Houdini 生效。 团队把插件放共享盘时,配置保持各自本机默认即可,永不落共享盘。
  • 快捷键:每条可改键一行(Paste as Object Merge、Copy Output Path)—— 点捕获框按下键位组合,点「应用」会话即时生效并持久化到配置目录的 hotkeys.json,每次启动自动应用;「恢复默认」清除该条自定义键位。
  • 自定义键优先;其次尊重 Hotkey Manager 中已有的键位;最后落默认值(Paste as Object Merge Ctrl+Shift+V、Copy Output Path Ctrl+Shift+C)。
  • 设置保存在本机配置目录下,换电脑或重装后重新设置一次即可。

Open Cache Folder打开缓存目录#

入口:右键带输出路径参数的节点(File Cache / ROP Geometry / FBX ROP / Mantra / Karma / USD Render 等)→ Open Cache Folder [HT]

直接在资源管理器中打开该节点的输出目录,免去翻参数、拷路径、开资源管理器的流程。

  • 按节点读取对应输出参数:File Cache / 几何缓存 / FBX 的 sopoutput、Mantra 的 vm_picture、Karma 的 picture、USD Render 的 outputimage。
  • USD Render 的 outputimage 未设置时,回退读取 loppath 指向节点(如 Karma Render Settings)的 picture;已设置时永远以 outputimage 为准。
  • 输出还没写出(目录不存在)时,自动上溯到最近存在的祖先目录。
  • 路径按 Houdini 变量语义展开($HIP/$OS/$F4 等),真相对路径再按 $HIP 拼接。

Reload Modules (Dev)开发热加载#

入口:HouTools → Reload Modules (Dev)

开发专用:重载所有 houtools 模块,改完代码无需重启 Houdini。已打开的工具窗口在 Reload 时自动关闭,重新打开即新代码;已打开的 Automation Python Panel 除外(由面板工具条的刷新按钮重建)。

仅开发环境可用:插件目录带 .git(git 仓库安装)自动启用;目录被拷贝安装(丢失 .git)时,在 Documents\houdiniXX.X\houdini.env 里加一行 HOUTOOLS_DEV = 1 并重启 Houdini 手动开启(H21/H22 各有一份,按需设置;开关唯一入口,不支持 Windows 用户环境变量,也不要写进随包分发的 HouTools.json)。发行版安装点击只会提示、不执行任何操作。另:Automation 任务执行中 Reload 会使剩余任务误判为"未知类型",请在引擎空闲时使用。
  • 按模块导入顺序(即依赖序)重载;houtools/dev 框架自身不参与重载(改动它需重启)。
  • 菜单结构(两份菜单 XML)的改动是 H22 硬约束,仍需重启 Houdini 一次才能生效。

安装#

  1. 点首屏「下载最新版」下载 HouTools.zip(GitCode Releases),整个解压到 Documents/houdini21.0/packages/(H21)或 Documents/houdini22.0/packages/(H22)——同一个包直装两版;解压后该目录下即有 HouTools 文件夹与 HouTools.json;
  2. 启动 Houdini,顶部菜单即出现 HouTools。
若需把 HouTools 文件夹放到其他位置,修改 packages/HouTools.json 里 $HOUDINI_PACKAGE_PATH/HouTools 的路径即可。仅支持 Windows:Automation 的窗口置顶用 Win32 API,部分工具的「打开所在文件夹」依赖 explorer。
